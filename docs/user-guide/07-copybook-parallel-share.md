## 抄经字帖

路由：`/sutra/[slug]/copybook`  
分卷：`?chapter=N`

### 是什么

将所选段落生成书法练习字帖，支持描红、多种格子与字体，导出 PNG 或 PDF。

### 从哪里进入

阅读页工具栏 **「开始抄经」**（保留当前卷参数）。

### 怎么操作

**左侧 · 抄经设置**

1. **选择段落** — 勾选本卷要抄写的段，可全选；总字数有上限，超出会截断并提示
2. **格子类型** — 米字格 / 田字格 / 九宫格 / 无格线
3. **书写模式** — 正常（黑字）/ 描红（浅红，默认）/ 临摹（浅灰）
4. **字体** — 玄冬楷书、青柳隶书、齐伋体等；显示字库覆盖率与缺字提示
5. **纸张** — 预设 6×8、8×10、10×12 格/页（A4），或自定义列数、格子大小
6. **繁体** — 勾选后抄经文本转为繁体

**右侧 · 预览与导出**

- 字体加载后自动生成多页 A4 预览
- **下载 PNG** — 每页一张图
- **下载 PDF** — 多页合并为 PDF

### 限制

- 当前主要为 **横排** 字帖
- 缺字字体可能用 fallback 或提示替换

## 平行阅读

路由：`/parallel/[slug]`

### 是什么

同一部经 **左右两栏** 并排对比不同文本版本（如底本 vs 白话），支持同步滚动。

### 从哪里进入

阅读页工具栏 **「平行阅读」**。

### 怎么操作

1. 顶栏左右 **版本下拉** 分别选择：底本、注疏、白话等（以该经可用数据为准）
2. **同步滚动** 开关：锁定后两栏滚动联动；解锁后可独立滚动
3. 各栏可独立 **简繁切换**；拼音跟随全局阅读偏好
4. 点击 **返回** 回到单栏阅读 `/sutra/[slug]`

---

## 分享

### 创建分享（阅读页）

1. 工具栏「分享」或段落旁分享图标
2. 在对话框中创建分享链接
3. 复制链接、复制带出处文字，或预览分享卡片

### 分享页

路由：`/share/[id]`

他人打开链接可看到：

- 经名、CBETA 编号、段序、摘录正文
- **复制文字**、**下载图片**、系统分享（若浏览器支持）
- **返回原文** → 跳转 `/sutra/[slug]`
- 浏览次数统计
