# 03 · 搜索与经藏

---

## 统一搜索

路由：`/search`  
带关键词：`/search?q=关键词`

### 是什么

一次检索同时覆盖 **经目、全文段落、辞典词条、知识图谱人物**，适合「我知道大概要找什么，但不确定在哪一类里」的场景。

### 从哪里进入

- 首页组合搜索框
- 顶栏「搜索」
- 六宫格「全文检索」

### 怎么操作

1. 输入关键词并搜索（支持经名简称，如「金刚经」「心经」「T08n0235」经号直查）
2. 使用顶部 **Tab** 筛选类型：全部 / 经目 / 段落 / 辞典 / 人物（数字为命中数）
3. **桌面端（lg 及以上）** 左侧 facet 侧栏可进一步筛选：
   - **部类**：多选部类（如般若、阿含）
   - **仅有白话**：只显示已导入白话层的经目及其段落
   - **清除**：重置筛选
4. 点击结果跳转：
   - 经目 → `/sutra/[slug]`
   - 段落 → `/sutra/[slug]#p-{段序}`
   - 辞典 → `/dictionary?q=…`
   - 人物 → `/person/[id]`

### 结果展示

- 分区标题：经目 · N、段落 · N 等
- **经目**按正典优先级排序（CBETA pagerank + 常见简称映射），简称如「金刚经」会优先显示「金刚般若波罗蜜经」（T08n0235）
- 段落按经分组，组内顺序与正典经目一致；snippet 中高亮匹配词
- 无结果时显示提示，并推荐热门经典

### 检索技巧

| 输入 | 效果 |
|------|------|
| 金刚经、心经 | 简称自动映射到正典全名 |
| T08n0235 | CBETA 经号直查 |
| 较长句子 | 以全文段落检索为主 |

### 平台差异

| 能力 | 桌面 | 移动 |
|------|------|------|
| Facet 侧栏 | 显示 | 隐藏（仍可用 Tab） |

## 经藏浏览

路由：`/canon`

### 是什么

按汉传大藏 **部类** 浏览站点已导入的全部经目，适合系统性地找经、按分类探索。

### 怎么操作

1. 点击部类标题 **展开 / 折叠** 手风琴（默认展开第一个部类）
2. 部类标题在滚动时会 **sticky** 吸顶，便于长列表浏览
3. 点击经目行 → 进入 `/sutra/[slug]`
4. 每行显示：经名、译者、CBETA 编号

### 空态

若尚未导入语料，页面提示「暂无已导入经目」。自托管站点需管理员执行语料导入，见 [管理员手册](../admin-guide/02-corpus-pipeline.md)。

---

## 搜索 vs 经藏

| 场景 | 推荐 |
|------|------|
| 知道关键词 | `/search` |
| 按部类浏览、看有哪些经 | `/canon` |
| 已知经名 slug | 直接 `/sutra/[slug]` |
