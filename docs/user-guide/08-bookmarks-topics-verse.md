## 我的收藏

路由：`/bookmarks`

### 是什么

保存阅读中标记的经目，便于下次继续。

### 怎么操作

1. 在阅读页工具栏点击 **收藏**（收藏整部经）
2. 打开收藏页查看列表
3. 点击经名 → `/sutra/[slug]` 或带段落锚点
4. 点击 **删除** 移除条目

### 数据说明

- 优先使用服务端 API 同步
- 服务端不可用时自动降级到 **localStorage**，页面会提示「当前使用本地存储」
- 清除浏览器数据可能丢失本地收藏

## 专题阅读

路由：`/topic/[slug]`（如 `/topic/kongxing` 空性）

### 是什么

按主题组织的导读与推荐经目阅读路径。

### 怎么操作

1. 从首页「专题阅读」卡片进入
2. 阅读 Hero 区标题、描述与经目数量
3. 阅读 **导读** 正文（Markdown 简化渲染）
4. 按序点击 **推荐经目** 进入阅读
5. 底部可返回首页

---

## 今日经句

路由：`/verse/today`

### 是什么

每日展示一句经文，可选 AI 短解读，适合分享与每日定课。

### 从哪里进入

- 首页「今日经句」卡片 → 「分享今日经句」

### 页面内容

- 日期、经句正文、出处经名
- 可选 AI 解读段落
- **阅读全文** → 对应 `/sutra/[slug]`（默认常见为心经等）

经句数据来自数据库 `daily_verse` 或站点默认句。
