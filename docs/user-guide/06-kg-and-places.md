## 知识图谱

路由：`/kg`

### 是什么

可视化探索佛教人物、经典、地点等实体及其关系。支持搜索消歧、推荐探索入口、力导向图与关系筛选。

### 怎么操作

1. 打开页面后默认搜索「玄奘」，左侧显示匹配结果列表（含关系数、朝代等消歧信息）
2. **点击搜索结果**或**推荐探索**芯片 → 中央力导向图加载关系网络
3. **单击图中节点** → 右侧「实体说明」更新；人物可跳转档案页
4. **双击节点** → 渐进展开该节点的邻居
5. **展开深度**滑块（1–4）与**关系类型**筛选控制子图范围
6. URL 自动同步（`?q=玄奘&slug=dila-A000294&depth=2`），可分享

### 节点颜色（类型）

| 类型 | 含义 |
|------|------|
| 人物 | 译者、法师等 |
| 典籍 | 经文文本 |
| 地点 / 寺院 | 地理相关 |
| 概念 | 术语、法相 |
| 朝代 | 时代 |

### 空态

若显示「暂无图谱数据，请联系管理员导入」，表示站点尚未导入知识图谱。

## 人物详情

路由：`/person/[slug]`（如 `/person/dila-A000294`）

### 是什么

展示单个人物条目的属性、相关经目与分组关系（师承、翻译等中文标签）。

### 从哪里进入

- 图谱页实体卡片「查看人物档案」
- 搜索「人物」结果
- 阅读页译者卡片（有规范数据时）

### 页面内容

- 中文名、英文名、生卒年、朝代/宗派
- 属性表（中文标签，最多 8 项）
- **相关经目** → 跳转阅读页
- **关系** → 按类型分组，人物/典籍/地点可继续点击

旧式技术 ID 链接会自动重定向到友好 slug。

## 佛教地理

路由：`/places`

### 是什么

在 MapLibre + Deck.GL 交互地图上展示圣地、寺院、人物与宗派点位，可选「师承传线」弧线。

### 怎么操作

- 勾选类型筛选（寺院 / 地点 / 人物 / 宗派）
- 开启「师承传线」查看师徒地理连线
- 点击地图点或右侧列表 → 弹出详情，可跳转人物或图谱
- 搜索框筛选地名

### 限制

- 无坐标实体不会出现在地图上
- 无数据时显示友好提示，需管理员导入带经纬度的地名实体
