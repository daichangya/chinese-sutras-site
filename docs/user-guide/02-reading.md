# 02 · 经文阅读

路由：`/sutra/[slug]`（例如 `/sutra/xinjing`）

大经分卷：`/sutra/[slug]?chapter=N`

---

## 是什么

经文阅读页是静心的核心：以纸色排版展示正文，支持白话切换、简繁转换、拼音注音，并提供目录、理解辅助（辞典 / AI / 相似段）、收藏与分享等工具。

---

## 从哪里进入

- 首页热门经典、搜索结果的经目/段落链接
- 经藏浏览 `/canon` 点击经名
- 专题页推荐经目
- 收藏页 `/bookmarks`
- 知识图谱人物页的「相关经目」

---

## 页面结构

### 经头

- CBETA 编号、部类、经名
- 译者（单行，有图谱数据时可跳转人物页）、字数
- 精简工具栏一行

### 工具栏

经头右侧为分组图标工具（`reader-toolbar`）：

| 分组 | 功能 |
|------|------|
| 目录（仅小屏） | 打开目录抽屉 |
| 字号 / 简繁 / 白话 | A−、A+、繁简切换；有白话层时显示白话按钮 |
| 收藏 / 分享 | 收藏整部经；分享当前激活段 |
| 对读 / 抄经 | 跳转平行阅读、字帖 |
| 理解（仅小屏） | 打开理解面板抽屉 |
| 设置 | 行距、拼音 |

> **说明：** 主题切换请使用顶栏按钮。字号仅通过工具栏 A± 调节。

### 分卷导航

篇幅较长的经典会按卷分页加载（每卷最多约 300 段）。顶部分卷按钮或 URL 参数 `?chapter=N` 切换卷。

### 正文

- 段落以 `prose-jx` 排版，支持 CBETA 异体字（缺字显示）
- 点击段落会将其设为「当前段」，驱动相似段落检索

### 侧栏（桌面 xl 及以上）

- **左侧**：目录（卷列表 + 段落采样锚点）
- **右侧**：理解面板（辞典 / 解释 / 相似 Tab）

### 小屏（xl 以下）

侧栏改为抽屉，通过工具栏「目录 / 理解」打开。

---

## 常用操作

### 切换白话与原文

若该经已导入白话层，工具栏显示「白话 / 原文」按钮。

### 简繁切换

工具栏「简 / 繁」按钮；偏好存 `localStorage`。

### 划选查词与 AI 解释

1. 在正文中拖选字词
2. 右侧理解面板（或抽屉）自动识别选区
3. 切换 Tab：
   - **辞典**：查询多源释义
   - **解释**：现代解释 / 背景 / 生活案例
   - **相似**：与当前段语义相近的段落
4. 点击「与 AI 深入讨论此段」跳转 `/chat`

### 收藏与分享

- **收藏**：整部经，已收藏后按钮禁用
- **分享**：工具栏分享当前激活段

### 阅读进度

进入经页时自动恢复上次阅读段落。

## 平台差异

| 能力 | 桌面 xl+ | 手机 / 平板 |
|------|----------|-------------|
| 目录 | 左侧常驻 | 抽屉 |
| 理解面板 | 右侧常驻 | 抽屉 |
| 行距 / 拼音 | 工具栏「设置」下拉 | 同左 |

---

## 常见限制

- **收藏粒度**：目前收藏整部经
- **白话 / 繁体**：取决于语料是否已导入
- **AI**：需站点配置 AI Gateway
