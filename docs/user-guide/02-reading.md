# 02 · 经文阅读

路由：`/sutra/[slug]`（例如 `/sutra/xinjing`）

大经分卷：`/sutra/[slug]?chapter=N`

---

## 是什么

经文阅读页是静心的核心：以纸色排版展示正文，支持白话切换、简繁转换、拼音注音，并提供目录、理解辅助（辞典 / AI / 相似段）、收藏与分享等工具。

---

## 从哪里进入

- 首页热门经典、搜索结果的经目/段落链接
- 经藏浏览 `/canon` 点击经名
- 专题页推荐经目
- 收藏页 `/bookmarks`
- 知识图谱人物页的「相关经目」

---

## 页面结构

### 经头

- CBETA 编号、部类、经名
- 译者（单行，有图谱数据时可跳转人物页）、字数

### 阅读工具（FAB + 右键）

经头下方**不再有**全宽工具栏。工具分为三处：

#### 右下角 FAB（`reader-fab`）

点击右下角叠层图标按钮展开常用操作：

| 操作 | 说明 |
|------|------|
| 朗读 | 从当前段连续朗读；播放中底栏控制 |
| 收藏 | 收藏整部经 |
| 对读 | 进入平行对读页 |
| 抄经 | 进入抄经字帖页 |
| 目录 / 理解（xl 以下） | 打开侧栏抽屉 |
| 设置 | 打开阅读设置面板 |

#### 设置面板

字号 A±、行距、拼音、简繁、白话、朗读引擎/语速。

#### 正文右键 / 长按（`reader-context-menu`）

| 操作 | 说明 |
|------|------|
| 分享此段 | 有划选分享划选段，否则分享当前段 |
| 复制 | 复制划选或当前段摘录 |
| 查辞典 | 在理解面板打开辞典 Tab |
| AI 解释 | 在理解面板打开解释 Tab |
| 从本段朗读 | 从右键所在段开始朗读 |

> **说明：** 主题切换请使用顶栏按钮。

### 分卷导航

篇幅较长的经典会按卷分页加载（每卷最多约 300 段）。顶部分卷按钮或 URL 参数 `?chapter=N` 切换卷。

### 正文

- 默认展示**经正文**（`body` / `verse` 段落），序跋等辅助段落在「经前序跋」折叠区（默认收起）
- 正文首段使用 `jx-paragraph-opening` 首字装饰，不会落在序文上
- 段落以 `prose-jx` 排版，支持 CBETA 异体字（缺字显示）
- 点击段落会将其设为「当前段」，驱动相似段落检索

### 侧栏（桌面 xl 及以上）

- **左侧**：目录（卷列表 + 段落采样锚点）；点击段落后正文滚动并同步高亮
- **右侧**：理解面板（辞典 / 解释 / 相似 Tab）

外链 `#p-{段序}` 或上次阅读进度会在进页时自动定位（hash 优先于进度）。

### 小屏（xl 以下）

侧栏改为抽屉，通过 FAB「目录 / 理解」打开。

## 常用操作

### 切换白话与原文

若该经已导入白话层，在 **设置面板** 中切换「白话 / 原文」。

### 简繁切换

在 **设置面板** 中切换；偏好存 `localStorage`。

### 划选查词与 AI 解释

1. 在正文中拖选字词——理解面板会显示当前选区，**不会自动调用 AI**
2. 获取释义的方式（任选其一）：
   - **右键 / 长按**正文 →「查辞典」或「AI 解释」
   - 在理解面板手动切换 Tab：**辞典** / **解释** / **相似**
3. 点击「与 AI 深入讨论此段」跳转 `/chat`

### 收藏与分享

- **收藏**：整部经，已收藏后按钮禁用
- **分享**：工具栏分享当前激活段

### 朗读（听经）

- 工具栏点击 **朗读**，从当前激活段起连续播放到本卷末尾
- **手机端**：底部固定控制条（播放/暂停、上下段、语速、引擎）
- **桌面端**：经头工具栏下方显示 slim 控制条
- 朗读文本 **跟随当前视图**（白话/繁体与屏幕一致；拼音仅视觉层）
- **高品质朗读**（默认已启用）：使用 Edge 神经语音，**无需 API Key**；设置中可切换「高品质 / 浏览器原生」
- 高品质模式支持锁屏播放/暂停；首次合成后会缓存到本地，同一段再次播放更快
- 高品质依赖 Edge 浏览器朗读服务（非微软官方商业 API），长期稳定性无官方承诺；流量增大后可配置 Azure 作为备选
- 浏览器原生朗读在 iOS 锁屏后可能暂停；切换分卷会自动停止朗读
- 播放中的段落以朱砂左边线高亮，并自动滚动到视野中央

### 阅读进度

进入经页时自动恢复上次阅读段落。

## 平台差异

| 能力 | 桌面 xl+ | 手机 / 平板 |
|------|----------|-------------|
| 目录 | 左侧常驻 | 抽屉 |
| 理解面板 | 右侧常驻 | 抽屉 |
| 朗读控制 | 经头下方 slim 条 | 底部固定控制条 |
| 行距 / 拼音 / 朗读设置 | 工具栏「设置」下拉 | 同左 |

---

## 常见限制

- **收藏粒度**：目前收藏整部经
- **白话 / 繁体**：取决于语料是否已导入
- **AI**：需站点配置 AI Gateway
