# 09 · 账号与微信登录

---

## 是否需要登录？

**不需要。** 静心默认可匿名阅读、搜索、查辞典与本地收藏。

登录是可选增强：登录后可在 **PC 与微信内** 同步阅读进度、书签与批注。

---

## 如何登录

1. 点击顶栏 **「微信登录」**，或访问 `/login`
2. **微信内打开**：自动跳转服务号网页授权
3. **PC 浏览器**：使用微信扫码（需站点已配置开放平台网站应用）

登录成功后进入 **个人中心**（`/account`），可查看昵称、绑定渠道与退出登录。

---

## 数据同步说明

- 本设备在登录前产生的进度/书签/批注，会在登录后 **自动合并** 到您的微信账号
- 在其他设备用同一微信登录后，服务器上的数据会保持一致
- 未登录时数据仍保存在本机（localStorage + 可选匿名同步）

---

## 隐私与安全

- 会话通过 HttpOnly Cookie 保存，不在 localStorage 存 token
- 登录后 API 以服务端 Session 为准，他人无法伪造您的 `userKey`
