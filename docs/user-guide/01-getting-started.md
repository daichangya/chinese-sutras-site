## 静心是什么

静心（jingxin）是现代化佛经阅读与理解平台，目标是帮助你在较短时间内**读懂一句、一段、一部经**，而不是只做经目检索。

- **无需注册**即可搜索、阅读、查辞典、体验 AI 辅助
- 经文数据基于 CBETA 等开放语料，详见 [关于页](/about) 版权说明
- AI 生成内容仅供学习参考，不能替代法师开示

## 首页首屏

打开 `/` 后你会看到：

1. **标题与 slogan** — 「让佛经更容易读懂」
2. **组合搜索框** — 输入关键词后回车或点搜索，跳转 `/search?q=…`
3. **热门标签** — 如金刚经、心经、净土等，一键搜索或跳转
4. **统计条** — 已导入经部数、段落数、辞典词条、知识实体（有数据时显示）
5. **六宫格入口** — AI 问经、辞典、经藏、全文检索、图谱、地理

向下滚动可见：

- **今日经句** — 每日一句，可跳转分享页或阅读原文
- **热门经典** — 快速进入常用经
- **专题阅读** — 如空性、净土、禅宗等主题路径

## 推荐第一次使用路径

适合新用户的 5 分钟路径：

1. 首页搜索框输入 **「心经」** → 进入搜索页
2. 点击经目 **《般若波罗蜜多心经》** → 进入阅读页
3. 阅读若干段，**拖选** 一句中的词（如「色即是空」）
4. 看右侧 **AI 面板** 的辞典 Tab 或「现代解释」Tab
5. 点击 **「与 AI 深入讨论」** → 进入 Chat 继续提问

更详细的阅读操作见 [02 经文阅读](./02-reading.md)。
